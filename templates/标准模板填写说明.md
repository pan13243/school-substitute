# 代课调课系统 · 标准导入模板填写说明

> 客户使用前请先通读本说明。

---

## 一、三个模板文件

| 文件名 | 内容 | 用途 |
|---|---|---|
| **总课表模板** | 5天×6节×20班矩阵 | 导入全校课表 |
| **课后服务模板** | 星期/时间段/项目/各班教师 | 导入课后服务安排 |
| **校历模板** | 周次/日期/单双周 | 导入学期校历 |

---

## 二、总课表模板填写规则

### 结构说明
- 每 **节次 = 2行**（科目行 + 教师行，成对出现）
- 节次名称和时间填在**每节第一行的第1、2列**
- 各班科目/教师填入对应列

### 填写步骤

**Step 1**：在第6行（班级名称行）填写班级名称

示例格式：
```
一（1）  一（2）  一（3）  二（1）  二（2）  ...
```

> 命名规则：年级用中文数字（一二三四五六），序号用阿拉伯数字，外套**全角括号**「（1）」。例如：五（3）、六（1）。

**Step 2**：每个节次填 2 行

以第一节为例：
```
第1行 A列填「第一节」 B列填「8:20-9:00」  其余各列填科目名
第2行 各列留空或填教师姓名
```

示例（3个班级的第一节）：
```
       时间        一（1）  一（2）  一（3）
第一节  8:20-9:00  语文     数学     英语
        （教师行） 张三     李四     王五
```

**Step 3**：按相同方式填完6个节次

节次时间参考（可按本校作息调整）：
- 第一节：8:20-9:00
- 第二节：9:10-9:50
- 第三节：10:30-11:10
- 第四节：11:20-12:00
- 第五节：14:00-14:40
- 第六节：14:50-15:30

### 常见问题

**Q：某班某节没有课怎么办？**
A：该单元格留空，解析时会自动跳过。

**Q：一个班同时有两位老师教同一科目怎么办？**
A：用「/」分隔，如「张三/李四」。系统会记录两位老师。

**Q：班级数少于20个怎么办？**
A：只填实际班级数对应的列，其余留空即可。

**Q：班级命名格式不对会怎样？**
A：系统会自动归一化，例如「1年级1班」会尝试转换为「一（1）」，但建议直接按格式填写以避免误差。

## 三、课后服务模板填写规则

### 结构说明
- 每行 = 一个时间段（星期 + 时间段 + 项目 + 各班教师）
- 单周和双周教师不同，用「/」分隔（格式：`单周教师/双周教师`）
- 同一教师通用，直接填一人姓名

### 填写步骤

**Step 1**：在第5行（表头）填写班级名称（与总课表一致）

**Step 2**：从第6行起填写数据

示例：
```
星期一  15:40-16:20  课后服务1  张三  李四  王五  ...
星期一  16:25-17:05  课后服务2  赵六  钱七  孙八  ...
```

### 项目名称规范

系统支持以下项目名称，请尽量使用：
- `课后服务1`、`课后服务2`、`课后服务3`（最常用）
- `晚自习`、`午休`
- `社团活动`

如需自定义项目名称，请联系技术支持确认兼容性。

### 单周/双周分隔格式

```
# 单周张三、双周李四
张三/李四

# 只有单周有，双周无人
张三/

# 两位老师不分单双周，通用
张三
```

## 四、校历模板填写规则

### 结构说明
- 每行 = 一个周次（周次 + 开始日期 + 结束日期 + 单双周）
- 日期格式：`YYYY-MM-DD`（如 2025-09-01）
- 单双周：根据该周属于单周还是双周填写

### 填写步骤

**Step 1**：确定学期第一周的周一日期，填入第1行开始日期

**Step 2**：结束日期 = 开始日期 + 6天

**Step 3**：根据周次奇偶判断单双周
- 第1、3、5、7...周 → 单周
- 第2、4、6、8...周 → 双周

### 备注栏用途
- 标注调休补课信息（如「周六上课，补周三」）
- 标注法定节假日（如「国庆节放假」）
- 其他需要说明的事项

---

## 五、导入流程

1. 整理好三个模板文件
2. 登录代课调课系统 → 管理后台
3. 进入「导入数据」页面
4. 按顺序导入：校历 → 总课表 → 课后服务
5. 导入后检查「全校课表」是否显示正确
6. 如有问题，删除数据后重新整理模板再导入
